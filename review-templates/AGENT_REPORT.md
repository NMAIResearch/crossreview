# Agent supporting report

Purpose: record observable actions, evidence and omissions alongside a Crossreview peer review.

One supporting report is enough: choose this agent report or the [human report](HUMAN_REPORT.md). You do not need both. Keep the claim verdicts and evidence in the peer-review form. An agent account is not independent verification by itself.

Use the actual session and evidence record. Give a safe relative file location, source passage, command result or session reference for each material assertion. Use "not done", "unavailable" or "unverified" where appropriate. Report failures and partial completion. Do not infer a person's satisfaction, understanding or motives, or describe unobservable model internals.

## Work and review scope

- Work, exact version or commit, and intended use:
- Question and checks agreed at the start:
- Scope actually reviewed, output produced and unfinished steps:
- Files, instructions and evidence supplied; later additions and when they arrived:
- Material changes to scope, evidence or criteria, alternatives considered and the person's approval or unresolved decision:
- Claims challenged, corrected or retained; contrary evidence and remaining search gaps:
- Sources, code or templates reused, original version, new use, checks and limits. Keep suggested reuse separate.

## Model and instruction provenance

- Application, declared model ID and provider; additional models and their roles:
- Visible model labels and execution records. Keep requested identity separate from verified backend identity:
- Requested effort or thinking setting, with invocation evidence; effective setting if exposed, otherwise "unverified":
- Documented context limit with its provider source; effective application limit if exposed, otherwise "unverified":
- Input truncation, missing material, compaction or other observed context limits:
- Operating instructions or card used, exact version and digest if available, and acknowledgement record. Keep private instructions and internal paths local:
- Prior participation in making the work, prior exposure to conclusions or earlier reviews, and reviewer independence limits:

## Sources and personal checks

- Search scope, exclusions and stopping point:
- Source access: full text, abstract, registry record, snippet or unavailable. Keep leads separate from source evidence:
- Original text, extraction or generated summary; quotations not checked against the original:
- Source copies and hashes retained, with safe relative locations, or what is missing:
- Claims supported only by the drafting agent's judgement:
- Separate source review actually completed: reviewer, version, exact scope, evidence and disposition, or "none":
- Human checks actually observed or reported. Label which; reading an output does not establish that its sources were opened:

Give a short, ranked set of checks still needed. For each, name the claim, decisive passage or input, access limit and why the check matters. A proposed check is not a completed one.
